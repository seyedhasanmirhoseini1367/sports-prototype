# Sports prototype

A clickable prototype of a sports social app (feed, challenges, training, events), built as one self-contained `index.html` with no frameworks or build step.

## Run locally

Open `index.html` in any browser.

## Deploy

The site is hosted as a **Render static site** at https://sports.hasanai.net.
Render auto-deploys on every push to `main`. There is no build command, and the publish directory is `.`.

To update the site, edit `index.html`, commit, and push to `main`.
